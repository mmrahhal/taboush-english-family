# طبوش العائلي — GitHub Pages + Firebase

هذه حزمة أولية تحول **منصة طبوش V4 بدليل المستخدم المدمج** إلى نسخة قابلة للنشر ومزامنة تقدم الأسرة.

## الخطوة 0 — الحسابات

- لديك حساب GitHub بالفعل.
- لست بحاجة إلى إنشاء حساب Google جديد إذا كان لديك حساب Google صالح، لكن يمكن إنشاء حساب جديد خاص بالمشروع من: https://accounts.google.com/signup
- لا تشارك كلمة مرور Google أو GitHub أو Firebase مع أي شخص.

## الخطوة 1 — إنشاء Firebase

1. افتح https://console.firebase.google.com/ ثم **Create a project** باسم `taboush-family` (قد يختار Firebase معرف مشروع مختلفًا).
2. يمكن تعطيل Google Analytics لهذا التطبيق العائلي.
3. أضف تطبيق **Web** من **Project overview → Add app → Web**.
4. انسخ إعدادات `firebaseConfig` إلى الملف `cloud-config.js` واستبدل القيم الأربع: `apiKey`, `authDomain`, `projectId`, `appId`. الإعدادات التعريفية الخاصة بتطبيق الويب ليست كلمة مرور؛ تظل قواعد الأمان ضرورية.
5. انتقل إلى **Build → Authentication → Get started → Sign-in method** وفعّل **Email/Password**.
6. من **Authentication → Users → Add user** أنشئ بريد ولي الأمر وكلمة مرور قوية. لا تُنشئ حسابات الأطفال في هذه النسخة.
7. انسخ **UID** لذلك المستخدم؛ ستحتاجه في قواعد الأمان.
8. انتقل إلى **Build → Firestore Database → Create database** واختر موقعًا مناسبًا، ثم انتقل إلى تبويب **Rules**.
9. افتح ملف `firestore.rules` واستبدل `FIREBASE_PARENT_UID` بالمعرّف الفعلي للمستخدم (UID)، ثم انسخ محتواه إلى تبويب Rules واضغط **Publish**. لا تستخدم قواعد `allow read, write: if true`.

> قاعدة الأمان هنا تسمح فقط لحساب ولي الأمر المحدد بقراءة وكتابة وثيقة أسرته، وتمنع جميع الوثائق الأخرى. لا يُنشئ الموقع مستخدمين جدد.

## الخطوة 2 — نشر GitHub Pages

1. أنشئ مستودعًا جديدًا باسم `taboush-english-family` على https://github.com/new.
2. في الخطة المجانية المعتادة، استخدم مستودعًا عامًا لتشغيل GitHub Pages. تذكّر أن **الكود سيكون عامًا لكن بيانات التقدم محمية عبر Firebase**.
3. ارفع الملفات التالية إلى **جذر المستودع**: `index.html`, `cloud.js`, `cloud-config.js`, `.nojekyll`، ويمكن إضافة `README_AR.md`.
4. **لا** ترفع ملفات النسخ الاحتياطية الخاصة بالطلاب، أو كلمات المرور، أو مفاتيح API السرية لخدمات الذكاء الاصطناعي.
5. اذهب إلى **Settings → Pages → Build and deployment**، واختر `Deploy from a branch` ثم `main` و `/(root)` واضغط Save.
6. سيظهر رابط قريب من `https://YOUR-USERNAME.github.io/taboush-english-family/`.
7. افتح الرابط من الآيباد وسجل دخول ولي الأمر، ثم أنشئ ملفات الأبناء من منصة طبوش.

## الخطوة 3 — التحقق من المزامنة

1. على جهاز أول، افتح الموقع وسجل الدخول بحساب ولي الأمر.
2. في أول دخول، عند غياب نسخة سحابية ستظهر رسالة تطلب منك قرار **رفع البيانات المحلية**. اختر نعم فقط إذا كنت تريد اعتماد بيانات هذا المتصفح كبداية.
3. أنشئ ملف طالب تجريبي وأكمل سؤالًا أو درسًا واضغط **حفظ سحابي الآن**.
4. على جهاز ثانٍ، افتح الرابط وسجل بالحساب نفسه؛ ينبغي ظهور الملف والنتائج.
5. جرّب مسار «إنجليزي الحياة» وأكمل موقفًا، ثم احفظ وحدث الصفحة على الجهاز الثاني.
6. جرّب تسجيل الخروج؛ ينبغي أن يتعذر التعامل مع واجهة الدروس قبل إعادة تسجيل الدخول.
7. صدّر نسخة احتياطية من لوحة الأسرة دوريًا.

## قيود واحتياطات مهمة

- **ليس موقعًا خاصًا بالكامل:** GitHub Pages يقدم الواجهة للعامة، لكن بيانات الطلاب خلف تسجيل الدخول وقواعد Firestore.
- **حساب عائلي واحد:** كل جهاز يستخدم بيانات دخول ولي الأمر. لا تشاركها خارج الأسرة، وسجّل الخروج على الأجهزة غير الموثوقة.
- **المزامنة ليست تعاونية لحظية:** آخر حفظ قد يستبدل تغييرات جهاز آخر إذا استُخدما في الوقت نفسه. استخدم جهازًا واحدًا في المرة أو اضغط «استعادة من السحابة» قبل البدء على جهاز آخر.
- **التخزين المحلي مستمر:** بيانات قديمة قد تظل على نفس الجهاز بعد تسجيل الخروج. لا تستخدم المنصة على أجهزة عامة.
- **الأمان والتقييم:** لم تُفعّل محادثة AI مفتوحة، ولم يُضف تقييم صوتي حقيقي؛ الواجهة الحالية تعمل كما في طبوش V4.
- **لا يمكن اختبار الاتصال الحقيقي** قبل تزويد التطبيق بإعدادات مشروعك ونشر قواعده.
- هذه نسخة عائلية تجريبية وليست تطبيقًا متعدد الأسر أو نظامًا إنتاجيًا مكتملًا.

## استكشاف المشكلات

| المشكلة | ما تفعل |
|---|---|
| إعدادات Firebase غير مكتملة | تأكد من استبدال كل `PASTE_` في `cloud-config.js` |
| `auth/invalid-credential` | تأكد من Email/Password ومن إنشاء المستخدم في Authentication → Users |
| `permission-denied` | طابق UID داخل قواعد Firestore وانشر القواعد، وتحقق من `projectId` |
| تعذر استيراد مكتبات Firebase | تحقق من الإنترنت وشبكة الجهاز؛ تحتاج ملفات SDK المتاحة عبر CDN |
| تعارض التقدم بين جهازين | صدّر نسخة احتياطية ثم اختر نسخة واحدة مرجعية؛ تجنب الاستخدام المتزامن |
| رابط GitHub يعرض 404 | تحقق من اسم `index.html` ومن Settings → Pages وانتظر اكتمال النشر |
